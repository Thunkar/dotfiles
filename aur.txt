# AUR WHITELIST — the ONLY packages apply.sh will build from the AUR, each
# pinned to a reviewed commit of its AUR git repo.
#
#   Format:  <package> <40-hex AUR git commit>      (trailing comments OK)
#
# Everything else lives in packages.txt and is installed as a signed binary
# via pacman. Building an AUR package runs its PKGBUILD as code on your
# machine — the vector abused in the June 2026 "Atomic Arch" attack, where
# ~1,600 orphaned AUR packages had their PKGBUILDs poisoned. Pinning means
# apply.sh checks out exactly the commit you read and refuses to build if
# that commit has vanished from the AUR history; an AUR helper would happily
# build whatever is at HEAD today.
#
# Adding or updating an entry:
#   1. Is it in a repo?  pacman -Si <pkg>   → then it goes in packages.txt.
#   2. ./aur-review.sh <pkg>   — shows history, diff since your pin, PKGBUILD.
#   3. Paste the "<pkg> <commit>" line it prints here. Re-run ./apply.sh.
# Unpinned entries are skipped with a warning, never built.
