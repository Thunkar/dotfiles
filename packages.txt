# fall back to building it from the AUR). AUR packages live in aur.txt.

# Before adding a name here it must resolve via `pacman -Si <pkg>`.
# Comments and blank lines are ignored; only the first word of a line counts.

# ── Printing / scanning (driverless) ───────────────────────────────
# Modern network printers/MFPs (e.g. the Brother DCP-L3560CDW) speak IPP
# Everywhere / AirPrint and eSCL, so no vendor driver — and no AUR package —
# is needed. CUPS discovers them over mDNS (avahi + nss-mdns are pulled in)
# and offers a temporary queue in every print dialog; apply.sh's
# ensure_printing enables the CUPS socket. Deliberately no cups-browsed.
cups                       # print server (cups.socket, socket-activated)
system-config-printer      # GTK printer/queue GUI, test pages
sane-airscan               # driverless (eSCL/WSD) scanner backend
simple-scan                # GTK scanner app
