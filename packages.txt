# ── Theming ────────────────────────────────────────────────────────
# Wallpaper-driven via matugen: it extracts a Material You palette from
# ~/.config/hypr/wallpapers/default.png and regenerates theme/colors.env
# (→ every .tpl in the repo) plus the GTK libadwaita colors.css.
#   - adw-gtk-theme: provides the adw-gtk3/adw-gtk3-dark GTK3 themes
#     that honour libadwaita @define-color, so the matugen colors.css
#     applies to GTK3 apps (Slack's menubar, GTK file pickers, etc.).
#   - qt6ct/qt5ct: Fusion widget style + a palette file rendered from
#     colors.env, so Qt apps (cliphist picker, pavucontrol, …) match.
#     KDE Frameworks apps stay un-themed on purpose; don't use them.
adw-gtk-theme                         # provides the adw-gtk3 + adw-gtk3-dark GTK themes
matugen                               # Material You palette generator (wallpaper → colors)
qt5ct                                 # Qt5 platform theme bridge
qt6ct                                 # Qt6 platform theme bridge
